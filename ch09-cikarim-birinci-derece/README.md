# Bölüm 9 — Birinci derece mantıkta çıkarım

AIMA 4. baskı, Bölüm 9 ile uyumlu **özgün Türkçe** öğrenme paketi.

**Durum:** 🟢 hazır

## Öğrenme hedefleri

1. **Önermeselleştirme** fikrini: FOL’ü sonlu domain’de önerme mantığına indirgeme sezgisini anlatmak.
2. **Birleştirme (unification)** ile iki terim/atomun ortak örneklerini bulmak.
3. **İleri / geri zincirleme** sezgisini Horn maddeleri üzerinde ayırt etmek.
4. **Çözümleme** eskizini ve “ne zaman hangi yöntem” tercihini özetlemek.

## Bu klasörde ne var?

| Dosya / klasör | İçerik |
|----------------|--------|
| `notlar.md` | Özgün Türkçe öğretim notları |
| `ornekler/birlesim_unification.py` | Eğitim `unify()` — sabit, değişken, f(x) |
| `ornekler/geriye_zincir.py` | Küçük Horn KB’de geriye zincirleme (özgün aile/suç senaryosu) |
| `alistirmalar.md` | 5 özgün alıştırma |
| `cozumler/` | A1 ve A2 çözümleri |
| `quiz.md` | 5 soru + cevaplar |

## Nasıl çalış?

1. AIMA Bölüm 9’u oku (yasal nüsha).
2. `notlar.md` ile pekiştir.
3. Örnekleri çalıştır:
   ```bash
   python ornekler/birlesim_unification.py
   python ornekler/geriye_zincir.py
   ```
4. Alıştırmalar → `cozumler/` → `quiz.md`.
