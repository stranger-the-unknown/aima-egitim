# Bölüm 27 — Alıştırmalar

Özgün sorular / tartışmalar. Kitap metnini kopyalamayın. Vaaz etmeyin; gerekçelendirin.

---

## A1 — Senaryo kartı

```bash
python ornekler/etik_senaryo_karti.py --demo
```

S1 (işe alım) için B veya C seçimini savunun: hangi gerilimleri kabul ediyorsunuz, hangilerini azaltıyorsunuz? 5–8 cümle.

## A2 — Kontrol listesi

```bash
python ornekler/guvenlik_kontrol_listesi.py --md --proje "ders-projesi"
```

Kendi mini projeniz (veya hayali bir öneri motoru) için listeden **en kritik 5 maddeyi** seçip neden kritik olduklarını yazın.

## A3 — Turing sınırı

Turing testini geçen bir sistem için hâlâ sorulması gereken **iki** soruyu yazın (güvenlik veya adillik veya anlam).

## A4 — Çin odası (tartışma)

Çin odası özetini kendi cümlelerinizle 4–6 cümlede yazın; ardından sistem yanıtı veya robot yanıtından **birini** seçip tek paragraf karşı-nüans ekleyin.

## A5 — Hizalama katmanı
