# A1 tartışma anahtarı — Senaryo kartı (işe alım)

Tek doğru yok; anahtar, gerilimleri açıkça saymaktır.

**B seçimi (ölç → eşik ayarla) tipik gerekçe:**

- Azalttığı: kör dağıtımla adillik riski; belirtim metriğinin (sadece “geçmiş başarıyı kopyala”) sorgulanması.
- Kabul ettiği: gecikme maliyeti, ölçüm yükü, “hangi grup?” tanım tartışması.

**C seçimi (insan + itiraz) tipik gerekçe:**

- Azalttığı: tam otomasyon sorumluluk boşluğu; kullanıcı itirazı ile hesap verebilirlik.
- Kabul ettiği: otomasyon yanlılığı (HR modeli yine “doğru” sayabilir); insan maliyeti; tutarsız insan kararları.

Değerlendirme: öğrencinin seçtiği eylemin gerilim listesiyle uyumlu gerekçe yazması yeterli; “tek ahlaki cevap” beklenmez.
