# Bölüm 16 — Basit kararlar alma (fayda teorisi)

AIMA 4. baskı, Making Simple Decisions temalarıyla uyumlu **özgün Türkçe** öğrenme paketi.
Tercihler, fayda, beklenen fayda maksimizasyonu (MEU), bilgi değeri ve karar ağlarına giriş.

**Durum:** 🟢 hazır

## Öğrenme hedefleri

1. Tercih ilişkisi ve fayda fonksiyonu fikrini açıklamak.
2. Belirsizlik altında MEU (maximum expected utility) ile eylem seçmek.
3. Bilgi değerini (value of information) yüksek seviyede tanımlamak.
4. Karar ağlarının (şans + karar + fayda düğümleri) iskeletini çizmek.
5. Küçük sayısal örneklerde beklenen faydayı hesaplamak.

## Bu klasörde ne var?

| Dosya / klasör | İçerik |
|----------------|--------|
| `notlar.md` | Özgün Türkçe öğretim notları |
| `ornekler/beklenen_fayda.py` | Piyango / tıbbi tedavi MEU hesabı |
| `ornekler/voi_mini.py` | Bilgi değeri sayısal mini demo |
| `alistirmalar.md` | 5 özgün alıştırma |
| `cozumler/` | A1 ve A2 çözümleri |
| `quiz.md` | 5 soru + cevaplar |

## Nasıl çalış?

1. AIMA’da basit kararlar bölümünü oku (yasal nüsha).
2. `notlar.md` ile pekiştir.
3. Örnekleri çalıştır:
   ```bash
   python ornekler/beklenen_fayda.py
   python ornekler/voi_mini.py
   ```
4. Alıştırmalar → `cozumler/` → `quiz.md`.
