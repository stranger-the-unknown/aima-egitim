# Bölüm 28 — Alıştırmalar (yansıtma)

Özgün yansıtmalar. Kitap metnini kopyalamayın.

---

## A1 — Yetenek haritası

```bash
python ornekler/yetenek_haritasi.py --yol ogrenme
```

(veya başka bir `--yol`) Çıktıdaki “sonraki adım”ı kendi takviminize 2 haftalık plan olarak yazın.

## A2 — Proje seçimi

```bash
python ornekler/proje_fikirleri.py
```

Listeden **bir** proje seçin; başarı ölçütü (ne demek bitti?) ve 3 kilometre taşı yazın.

## A3 — Zayıf halka

Quiz’lerde en çok zorlandığınız 1–2 bölümü adlandırın; her biri için tek bir tekrar eylemi (kod yeniden çalıştır / alıştırma / özet) seçin.

## A4 — AGI dili

AGI hakkında bir iddiayı (medya veya kendi cümleniz) alın; altına “kanıt / varsayım / belirsizlik” diye üç satır yazın.

## A5 — Tamamlayıcı beceri

Sadece model eğitmek dışında portföyünüze ekleyeceğiniz bir tamamlayıcı beceri seçin (test, HCI, güvenlik, veri hattı…) ve nedenini 3 cümleyle açıklayın.
