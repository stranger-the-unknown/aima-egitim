## Öğrenme hedefleri (önizleme)

1. Bilgi tabanlı ajanın algı–bilgi–eylem döngüsünü tarif etmek.
2. Önermeler mantığında doyma, çıkarım ve basit model kontrolü fikrini kullanmak.
3. Wumpus dünyası gibi oyuncak ortamlarda mantıksal temsilin rolünü görmek.
