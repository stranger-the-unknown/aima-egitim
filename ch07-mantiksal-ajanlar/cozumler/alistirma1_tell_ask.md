# A1 çözümü — Tell / Ask

Örnek tur:

1. **Algı al** (sensörler).
2. **Tell(KB, algı cümlesi)** — gözlemi bilgi tabanına yaz.
3. **Ask(KB, “ne yapayım?” / “şu kare güvenli mi?”)** — çıkarım.
4. **Eylemi uygula**; isteğe bağlı Tell ile eylemi de kaydet.

`Tell` bilgiyi günceller; `Ask` KB’nin gerektirdiği cevabı arar.
