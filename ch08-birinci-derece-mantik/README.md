# Bölüm 8 — Birinci derece mantık

AIMA 4. baskı, Bölüm 8 ile uyumlu **özgün Türkçe** öğrenme paketi.

**Durum:** 🟢 hazır

## Öğrenme hedefleri

1. **Önermeler mantığı ile FOL farkını** nesneler, ilişkiler ve fonksiyonlar üzerinden açıklamak.
2. **Niceleyicileri** (∀, ∃) okuyup yazmak; etki alanını (domain) sezgisel anlatmak.
3. Basit bir bilgi tabanını Python önekleri/olgularıyla modellemek; evrensel örnekleme / örüntü eşleme ile sorgu sormak.
4. Türkçe cümle ↔ FOL gösterimi çevirisini öğrenme aracı olarak kullanmak.

## Bu klasörde ne var?

| Dosya / klasör | İçerik |
|----------------|--------|
| `notlar.md` | Özgün Türkçe öğretim notları |
| `ornekler/fol_sozluk.py` | Küçük FOL-benzeri KB: Parent/Ancestor olguları + UI sorguları |
| `ornekler/fol_ceviri.py` | Türkçe ↔ FOL dizi çeviri demosu |
| `alistirmalar.md` | 5 özgün alıştırma |
| `cozumler/` | A1 ve A2 çözümleri |
| `quiz.md` | 5 soru + cevaplar |

## Nasıl çalış?

1. AIMA Bölüm 8’i oku (yasal nüsha).
2. `notlar.md` ile pekiştir.
3. Örnekleri çalıştır:
   ```bash
   python ornekler/fol_sozluk.py
   python ornekler/fol_ceviri.py
   ```
4. Alıştırmalar → `cozumler/` → `quiz.md`.
