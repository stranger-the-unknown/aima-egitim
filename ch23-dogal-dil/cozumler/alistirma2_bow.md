# A2 çözümü — BoW

Eğitimdeki pozitif / negatif (veya konu) sözcük sayımları test cümlelerini doğru sınıfa iter — derlem çok küçük olduğu için “ezber benzeri” başarı beklenir.

Ters örnek: pozitif kelimeleri çıkarıp “berbat / kötü / rezalet” eklediğinizde etiket negatif tarafa kaymalıdır. Kaymazsa sözlükte o olumsuz sözcüklerin az / hiç geçmediğini kontrol edin.

BoW sınırı: alay / olumsuzlama (“hiç iyi değil”) kolay kaçabilir — A4 ile bağlantılı.
