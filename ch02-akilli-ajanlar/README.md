# Bölüm 2 — Akıllı ajanlar

AIMA 4. baskı, Bölüm 2 ile uyumlu **özgün Türkçe** öğrenme paketi.

**Durum:** 🟢 hazır

## Öğrenme hedefleri

1. **Ajan fonksiyonu** ile **ajan programı** arasındaki farkı açıklamak.
2. PEAS’i yeniden kullanarak ortamı daha sistematik sınıflandırmak.
3. Ortam özelliklerini (gözlem, determinizm, dinamiklik, …) derinlemesine ayırt etmek.
4. Ajan mimarilerini karşılaştırmak: basit refleks, modele dayalı, hedefe dayalı, faydaya dayalı, öğrenen (eleştirmen / öğrenme öğesi / performans öğesi / problem üreteci).
5. Verilen senaryoya uygun mimariyi seçmek ve basit bir modele dayalı ajanı kodda çalıştırmak.

## Bu klasörde ne var?

| Dosya / klasör | İçerik |
|----------------|--------|
| `notlar.md` | Özgün Türkçe öğretim notları |

| `ornekler/ajan_mimarileri_karsilastirma.py` | Ajan türleri karşılaştırma tablosu |
| `alistirmalar.md` | 5 özgün alıştırma |
| `cozumler/` | İlk 2 alıştırmanın çözümleri |
| `quiz.md` | 5 soru + cevaplar |

## Nasıl çalış?

1. AIMA Bölüm 2’yi oku (yasal nüsha).
2. `notlar.md` ile pekiştir.
3. Örnekleri çalıştır:
   ```bash
   python ornekler/model_based_vacuum.py
   python ornekler/ajan_mimarileri_karsilastirma.py
   ```
4. Alıştırmaları çöz; `cozumler/` ve quiz ile kontrol et.
